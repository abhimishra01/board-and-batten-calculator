# Code review, readability lens (Hermione)

Verdict: the code is mostly easy to follow and the maths and article table check out (all 10 table cells recomputed and match; 15 test groups pass), but one leftover template string leaks into every meta description, and a few misleading names and dead lines will slow a new engineer. Must-fix: 1.

Known template leftovers (README, new-tool.sh, tracked screenshots, duplicate legal links, build-date "Last updated", British spelling in legal pages): not repeated here.
